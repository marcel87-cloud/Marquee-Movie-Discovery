# Marquee-Movie-Discovery
This project is made using React (JavaScript), Vite, Material UI, REST API 

This project also includes;
A. Homepage and Layout
Create a homepage inspired by the supplied screenshot. Include:
• A top bar with your application name or logo and a search field.
• A sidebar or navigation menu with Home, Movies, TV Shows, and My Watchlist.
• Movie and TV show posters displayed in organised rows or grids.
• At least three content sections, such as Trending, Popular Movies, Action Movies, or Popular TV
Shows.
• A consistent dark theme, clear spacing, readable text, and suitable hover effects.
Create your own branding. The interface should be recognisably inspired by the reference; an exact
copy is not required.
WEB AND MOBILE APPLICATION DEVELOPMENT PRACTICAL ASSIGNMENT
3. What You Must Build (continued)
B. Live Movie and TV Data
Connect the application to one real movie information API. You may use:
• TMDB API;
• An IMDb data API available through RapidAPI; or
• Another suitable API approved by the lecturer.
Use the API to display available information, such as titles, posters, release dates, ratings, genres,
and descriptions. Do not hardcode the movie catalogue. APIs may provide different fields; handle
missing values appropriately.
C. Search
Allow users to search for movies or TV shows by title. Search results must come from the selected
API. Display a clear message when there are no matches, and indicate when results are loading or
a request fails.
D. Movie and TV Show Details
Clicking a movie or TV show must open a details page or dialog containing the following information,
where available:
• Title and poster;
• Overview or storyline;
• Release date or year;
• Rating; and
• Genre.
E. Navigation and Categories
Users must be able to navigate between Home, Movies, TV Shows, and My Watchlist. Use React
Router for navigation.
The Movies page must show movies, and the TV Shows page must show TV series. Implement at
least one working category or genre filter, depending on the capabilities of your selected API.
F. My Watchlist
Allow users to add items to a watchlist, view saved items, and remove them.
Store the watchlist in the browser using localStorage, so that saved items remain available after
refreshing the page. A login system is not required.
G. Responsive Design
The application must be usable on desktop, tablet, and mobile screens. On smaller screens, adjust
the poster layout and provide an appropriate navigation menu. Avoid horizontal page overflow and
unreadably small text.
